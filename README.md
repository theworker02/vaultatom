# vaultatom

Vault config/atom key checks for twelve-factor services.

**Site:** https://theworker02.github.io/vaultatom/

## Install / run

```bash
git clone https://github.com/theworker02/vaultatom.git
cd vaultatom
node src/cli.js
node --test
```
